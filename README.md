# Liczby po hiszpańsku

Ćwiczenie zapisu liczb 1–999 po hiszpańsku. Bez backendu i API — statystyki zapisują się w `localStorage` przeglądarki.

## Uruchomienie lokalnie

```bash
npm install
npm run dev
```

## Publikacja na GitHub Pages

1. Wrzuć repo na GitHub (gałąź `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. Każdy push na `main` automatycznie buduje i publikuje stronę.

## Skróty

Enter – sprawdź · N – nowa liczba · M – pokaż odpowiedź (po błędnej próbie)
